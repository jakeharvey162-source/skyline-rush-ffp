How to install the Windows download
  1. Download every numbered archive part into the same folder. All parts are required.
  2. Install 7-Zip from its official website, then extract the file ending in .7z.001. Do not extract each part separately.
  3. Open the extracted skyline-rush folder. Start skyline-rush.bat for practice or skyline-room.bat for multiplayer.
  4. If your browser interrupts a download, retry the affected part. Compare its SHA-256 with SHA256SUMS.txt if you suspect a damaged download.
